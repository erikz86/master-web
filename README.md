# master-web

Static website project.

## Structure
```
master-web/
├── assets/
│   ├── css/    # Stylesheets
│   ├── img/    # Images
│   └── js/     # JavaScript
├── pages/      # Additional HTML pages
└── index.html  # Landing page
```

## Setup
Buka `index.html` di browser, atau serve dengan:
```bash
python3 -m http.server 8000
```
